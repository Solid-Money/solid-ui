# Cashback link font

`SolidLink-Bold.ttf` is derived from `MonaSans_700Bold.ttf` in
`@expo-google-fonts/mona-sans` version 0.4.1. The glyphs, outlines, kerning,
and layout metrics are unchanged.

The original `post.underlineThickness` is 320 units per 1000 em, which makes
native iOS underlines cover the bottom of the text. This variant sets it to
50 units (1 point at the links' native 20-point font size). The underline
position remains unchanged. Font names are changed to **Solid Link** in
accordance with the original font's reserved-name requirement. The font
table checksums and `head.checkSumAdjustment` have been recalculated.

The app loads this variant as `SolidLink_700Bold` for the two cashback
disclaimer links. Other text keeps the original fonts.

Copyright and license metadata remain in the font. The original SIL Open
Font License is also included in `SolidLink-OFL.txt`.
